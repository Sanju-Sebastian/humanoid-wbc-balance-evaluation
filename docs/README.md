# Thesis Documents

## Thesis Report
**File:** `Sanju_N_Sebastian_Master_Thesis_2026.pdf`

Full master's thesis submitted in partial fulfillment of the degree of MSc in 
Robotics and Automation at University West, Sweden, 2026.

**Covers:**
- Literature review of whole-body control architectures
- MuJoCo simulation environment and Unitree H1 model setup
- Implementation of four WBC controllers (WQP, HQP, Passivity, LQR-on-LIPM)
- Stochastic multi-push disturbance evaluation protocol
- Residual MLP design, ablation, and statistical evaluation
- Results, discussion, and conclusions
